# Vexil Search v0.2.0 — Modern Command Palette, Quick Look & Smarter Local Search 🚀

We are excited to release **Vexil Search v0.2.0**! This major update brings a modern desktop command palette, customizable global hotkeys, instant file preview with Quick Look, a built-in duplicate file finder, and multi-platform performance improvements across Windows, macOS, Linux, and Android.

---

### ✨ What's New in v0.2.0

#### ⚡ Modern Command Palette

- **Redesigned Spotlight Experience**: Elevated glassmorphic command bar with acrylic blur, responsive layout, and ambient focus glow.
- **Interactive Action Controls**: Instant one-click clear button (`✕`), favorite search bookmarking (`★`), and direct hotkey badge.
- **Search History & Quick Syntax Chips**: Access recent searches with individual removal and quick-insert filter pills (`ext:pdf`, `ext:docx`, `size:>10mb`, `date:today`).

#### ⌨️ Customizable Global Hotkeys

- **Summon From Anywhere**: Toggle Vexil instantly from anywhere in Windows and macOS.
- **Interactive Shortcut Recorder**: Choose from popular presets (`Alt + Space`, `Ctrl + Shift + Space`, `Ctrl + Space`, `Alt + F`) or record your own personal key combinations directly in Preferences.

#### 👁️ Spacebar Quick Look Preview

- **Instant File Peek**: Press **Space** on any search result to open a rich preview card with file snippets, metadata, file size, and timestamps without launching heavy third-party applications.
- **Full Keyboard Navigation**: Navigate results with Arrow keys, open files with Enter, and copy paths instantly with `Ctrl+C` / `Cmd+C`.

#### 🔍 Smarter, Deeper Local Search

- **Enhanced Full-Text Search (FTS5)**: Weighted BM25 relevance scoring prioritizing exact name matches, title matches, and content relevance.
- **Expanded File Type Support**: Fast deep extraction for PDF, DOCX, TXT, Markdown, RTF, ODF/ODT, and 40+ programming language source files.
- **100% Private & Offline**: All indexing, text extraction, and searches occur strictly on your local device — zero cloud telemetry, zero data leaves your machine.

#### 🧹 Duplicate File Finder

- **Reclaim Disk Space**: Scan and identify identical files across your indexed paths using fast SHA-256 content hashing. Safely manage and remove redundant duplicates.

#### 📁 Multi-Select Bulk Actions & Context Menus

- **Batch Processing**: Multi-select files with Shift/Ctrl click to copy paths, export result lists, or move items to the safe retention Trash with undo support.
- **Right-Click Context Menu**: Instant access to Open, Reveal in File Explorer / Finder, Copy Full Path, or inspect file details.

#### 📱 Android Improvements

- **Native Android APK**: High-performance local search for your phone and tablet with background indexing and low battery footprint.

### 📦 Downloads & Installation

Choose the package for your operating system from the **Assets** section below:

- **Windows**: `.msi` (Installer) or `.exe` (Setup)
- **macOS**: Universal `.dmg` (Apple Silicon & Intel)
- **Linux**: `.AppImage`, `.deb`, or `.rpm`
- **Android**: Signed `.apk` (Release build)

Existing installations will automatically prompt with an in-app update banner.
